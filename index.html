How to Enable EFS Folder Encryption in Windows 10

Securing your files in Windows 10 using the native Encrypting File System (EFS) is powerful, but navigating registry limitations, certificate backups, and Windows Home edition restrictions can be confusing. Here is the complete guide to doing it right.

Editorial Team Updated: October 2023 12 min read
Quick Answer

To encrypt a folder in Windows 10: Right-click the folder, select Properties, click Advanced, and check the box that says Encrypt contents to secure data. Click OK and Apply. Note: If this box is greyed out, you are likely using Windows 10 Home (which does not support EFS natively) or the EFS registry key is disabled.

What You Need Before Starting (Requirements)

Before modifying your system settings, it is crucial to understand that EFS is heavily dependent on your specific Windows 10 edition. Enabling file encryption natively is not universally available across all Microsoft operating systems.

How Modern Encryption Algorithms Work in EFS

When you enable EFS on a folder, Windows utilizes a combination of symmetric and asymmetric encryption to protect your data. It generates a File Encryption Key (FEK) using advanced algorithms (typically AES-256 in modern Windows 10 builds).

This FEK is what actually encrypts the contents of your file. However, to keep that key safe, Windows then encrypts the FEK itself using the public key from your user account's EFS certificate. This means the data is bound directly to your specific Windows user profile.

How Encryption Protects Data at Rest vs in Transit

EFS provides protection for data at rest. This means if someone steals your physical hard drive, or logs into the computer using a different Windows account, they cannot read the files. However, if you attach an EFS-encrypted file to an email and send it over the internet (data in transit), Windows decrypts it before attaching it. EFS does not protect files once they leave your NTFS drive.

Method 1: Native EFS Setup Walkthrough (Step-by-Step)

If you are running Windows 10 Pro, Enterprise, or Education, you can enable EFS folder encryption directly through the file properties menu without installing third-party software.

  1. Locate your target folder: Open File Explorer and navigate to the folder you want to protect.
  2. Open Properties: Right-click the folder and select Properties from the context menu.
  3. Access Advanced Attributes: Under the General tab, locate the Attributes section and click the Advanced... button.
  4. Enable Encryption: In the Advanced Attributes window, check the box labeled Encrypt contents to secure data.
  5. Apply Changes: Click OK, then click Apply on the main Properties window.
  6. Choose Scope: A prompt will ask if you want to apply changes to "this folder only" or "this folder, subfolders and files". For maximum security, select the second option to ensure all current and future contents are encrypted.

How to Verify It Worked

Once applied, the names of the encrypted files and folders will appear in green text in File Explorer (depending on your display settings), and a small padlock icon will appear on the file icon. You will still be able to open them normally while logged into your account, but other users on the PC will receive an "Access Denied" error.

Fix 'Encrypt Contents to Secure Data' Greyed Out

The most common issue users face is finding the encryption checkbox entirely greyed out and unclickable. This happens for one of three primary reasons.

Problem / Cause How to Fix It
Windows 10 Home Edition
Home does not support EFS natively.		 You must either upgrade to Windows 10 Pro or use third-party file encryption software.
Wrong File System (FAT32)
EFS only works on NTFS drives.		 Format the drive to NTFS, or move the folder to your primary C: drive (which is NTFS).
Registry Key Disabled
NtfsDisableEncryption is set to 1.		 Run the fsutil command in Command Prompt (shown below) to re-enable EFS routing.

Enable EFS via Command Prompt (fsutil)

If you are on Windows 10 Pro but the option is still greyed out, your registry might be blocking it. You can fix this by updating the NtfsDisableEncryption registry behavior.

Open Command Prompt as an Administrator and paste the following code:

fsutil behavior set disableencryption 0

Restart your computer after running this command to apply the registry changes.

Owner-Safe Access Denied Fixes

If you encounter access denied: checkprefs access denied while trying to read your own files, ensure you are logged into the exact user profile that encrypted the files. If you recently reinstalled Windows, you must import your backed-up PFX certificate to regain access.

How to Backup Your EFS Certificate in Windows 10

Key management best practices dictate that you must export your certificate immediately after encrypting your first file. Without this backup, a corrupted Windows profile means permanent data loss.

  1. Press the Windows Key + R, type certmgr.msc, and press Enter.
  2. In the left pane, expand Personal and click on Certificates.
  3. Locate the certificate that lists "Encrypting File System" under Intended Purposes.
  4. Right-click it, go to All Tasks, and select Export.
  5. In the wizard, ensure you select Yes, export the private key.
  6. Save the resulting .pfx file to an external, secure USB drive and protect it with a strong password.

Alternatively, advanced users can use the certutil tool via command line:

certutil -user -exportpfx My efs_backup.pfx

EFS vs BitLocker: Which Should You Use?

Windows offers two distinct encryption tools. BitLocker is a Full Disk Encryption (FDE) tool, while EFS is a file-level encryption tool. They serve different purposes and can even be used together.

Feature Encrypting File System (EFS) BitLocker
Scope of Protection Individual files and folders Entire drives and partitions
Protection Mechanism Tied to Windows user account Tied to hardware (TPM chip) or PIN
Best Used For Protecting files from other users on the same PC Protecting data if the physical laptop is stolen
Performance Impact Minimal (only affects specific files) Slight system-wide overhead during read/write
Windows 10 Home Support No (Pro/Enterprise only) No (Requires Pro/Enterprise)

Frequently Asked Questions

How to enable EFS in Windows 10 Home?

You cannot enable EFS natively in Windows 10 Home. Microsoft restricts this feature to Pro, Enterprise, and Education editions. Home users must use third-party encryption software to protect folders.

Why is 'Encrypt contents to secure data' greyed out?

This usually happens for three reasons: you are using Windows 10 Home, the drive is formatted as FAT32 instead of NTFS, or the EFS service has been disabled via the registry.

Can EFS encrypted folders be accessed by another user?

No. By default, only the Windows user account that encrypted the file can access it. Other administrators on the same machine will receive an Access Denied error unless you explicitly share the certificate with them.

Does encryption slow down my PC significantly?

File-level encryption like EFS has virtually no noticeable impact on modern PCs, especially those with Solid State Drives (SSDs). The AES algorithm is hardware-accelerated by most modern CPUs.

What happens to encrypted files if I forget the password?

If you lose your Windows account password and cannot log in, and you do not have a backup of your EFS .pfx certificate, the encrypted files are permanently unrecoverable. There is no backdoor.

How to remove EFS encryption from a folder?

Right-click the folder, go to Properties > Advanced, and uncheck the "Encrypt contents to secure data" box. Click OK and Apply. You must be logged into the authorized user account to do this.
